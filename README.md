# Hangman-Game
Классическая консольная игра "Виселица" на Python / The simple Hangman game written in Python.

## Русский
 
Классическая консольная игра **«Виселица»**, написанная на языке Python.
 
### 🎮 Особенности проекта
* Полностью текстовый (консольный) интерфейс.
* Поддержка двух языков интерфейса (русский и английский).
* Случайный выбор слов из встроенных текстовых словарей.
 
### 📚 Использованные материалы
При создании игры были использованы базы слов других разработчиков с GitHub. Большое спасибо авторам за их работу:
1. Список английских слов — https://github.com/edthrn/most-common-english-words/blob/master/nouns.txt
2. Список русских слов — https://github.com/Harrix/Russian-Nouns/blob/main/dist/russian_nouns.txt
 
### 🚀 Как запустить игру
1. Убедитесь, что у вас установлен [Python 3](https://python.org).
2. Скачайте все файлы репозитория в одну папку.
3. Откройте терминал/консоль в этой папке и запустите главный файл:
   ```bash
   python main.py
   ```

## English
 
A classic command-line **Hangman** game written in Python.
 
### 🎮 Features
* Fully text-based (console) interface.
* Multi-language support (Russian and English).
* Random word selection from built-in dictionaries.
 
### 📚 Credits & Acknowledgments
I used word databases created by other developers on GitHub. Special thanks to the authors:
1. English word list file — https://github.com/edthrn/most-common-english-words/blob/master/nouns.txt
2. Russian word list file — https://github.com/Harrix/Russian-Nouns/blob/main/dist/russian_nouns.txt
 
### 🚀 How to run
1. Make sure you have [Python 3](https://python.org) installed.
2. Download all files from this repository into a single folder.
3. Open your terminal/command prompt in that folder and run the main file:
   ```bash
   python main.py
   ```
